TeacherJi v2 — Autonomous Learning System
Architecture Design Document (Final)

Version: 2.0

Architecture: Autonomous Agentic Learning System

Core Philosophy: Don't build an AI that answers questions. Build an AI that continuously decides how to maximize a student's learning.

Executive Summary

Most AI tutoring systems today are built using a simple Retrieval-Augmented Generation (RAG) pipeline.

Student
      ↓
Retriever
      ↓
LLM
      ↓
Answer

While these systems can answer questions, they do not reason about learning.

TeacherJi v2 is designed around a fundamentally different philosophy.

Rather than generating responses, the system continuously reasons about:

what the student actually needs
whether the requested topic should even be taught
which concepts should be revised first
which teaching strategy should be used
how to verify learning
how to adapt future lessons

TeacherJi therefore behaves less like a chatbot and more like an autonomous educational operating system.

Design Philosophy

The objective of TeacherJi is not to maximize response quality.

The objective is to maximize student learning.

Every response generated by the system is simply the consequence of a much larger reasoning process.

The AI continuously asks itself:

What is the student's actual goal?
What does the student already know?
What knowledge is missing?
Which teaching strategy is most effective?
Which tools should I use?
Was my explanation successful?
How should future lessons change?

The system therefore becomes decision-driven instead of response-driven.

Core Principles
1. Decisions Before Generation

Large language models are very good at generating text.

Good tutors are good at making decisions.

TeacherJi prioritizes decision making over response generation.

Examples include:

Teach the requested topic
Skip already-mastered content
Revise prerequisite concepts
Generate a visual explanation
Create an analogy
Increase difficulty
Reduce complexity
Switch teaching strategy
Start a quiz instead of another explanation

Every lesson begins with reasoning rather than generation.

2. Dynamic Planning

Traditional educational systems follow predefined lesson flows.

TeacherJi continuously replans.

Example:

Teach Fractions

↓

Student struggles

↓

Planner inserts prerequisite lesson

↓

Student understands

↓

Planner increases difficulty

↓

Continue

Planning never finishes.

Every interaction changes future execution.

3. Long-Term Personalization

Instead of remembering conversations, TeacherJi remembers learning.

Each student develops an evolving learning profile.

The system stores:

mastered concepts
weak concepts
confidence levels
preferred explanation styles
revision history
learning pace
misconception patterns

Future lessons automatically adapt using this information.

Component Overview
1. Supervisor
Responsibility

The Supervisor is the brain of the system.

It never teaches.

It never retrieves documents.

It never generates quizzes.

Its only responsibility is making high-level decisions.

Examples:

Should teaching begin?
Should prerequisites be revised?
Should the student be assessed?
Should memory be consulted?
Should another explanation be generated?
Which workflow should execute next?

The Supervisor coordinates every other component.

2. Learning Agent

The Learning Agent performs all educational reasoning.

Unlike traditional tutor agents, this component does not execute a fixed prompt.

Instead it receives an educational objective and autonomously decides how to achieve it.

Possible responsibilities:

teaching concepts
diagnosing misconceptions
generating quizzes
explaining differently
adapting difficulty
answering follow-up questions
selecting tools

The Learning Agent is the only reasoning component allowed to invoke educational tools.

3. Memory Agent

The Memory Agent maintains the student's long-term learning profile.

Instead of storing conversations, it stores educational knowledge.

Example information:

Learning Style

Mastered Topics

Fractions
Decimals

Weak Topics

Division
Ratios

Confidence

Moderate

Preferred Explanations

Examples
Visual Diagrams

This information influences every future planning decision.

4. Reflection Agent

Reflection is the final quality control stage.

Before any response reaches the student, the Reflection Agent critiques it.

Evaluation criteria include:

factual correctness
curriculum alignment
difficulty level
hallucination risk
explanation quality
JSON validity
educational usefulness

If quality is unacceptable, execution returns to the Learning Agent for another attempt.

The student never sees unreviewed outputs.

The system distinguishes between reasoning agents and tools.

Agents make decisions.

Tools execute tasks.

↓

↓

↓

↓

Reflect

The response is therefore the final product of multiple reasoning stages rather than a single LLM call.

Why This Is Truly Agentic

TeacherJi satisfies the defining properties of modern autonomous AI systems.

Goal-Oriented

The system optimizes learning outcomes instead of generating responses.

Planning

Plans are continuously updated throughout execution.

Tool Selection

The Learning Agent dynamically decides which tools are required rather than following fixed workflows.

Reflection

Every response is evaluated before being delivered.

Memory

Persistent learner models influence future reasoning.

Adaptation

Teaching strategies evolve based on student performance.

Autonomy

The system independently determines the next best educational action rather than executing hardcoded pipelines.

Future Extensions

The architecture is intentionally modular.

Future capabilities can be added as additional tools without changing the reasoning architecture.

Potential additions include:

Voice-based tutoring
OCR for handwritten notes
PDF curriculum ingestion
Interactive simulations
Teacher dashboards
Parent dashboards
Multi-modal diagram generation
Classroom analytics

Because reasoning is separated from execution, the system can evolve by simply expanding its available tools while preserving the same autonomous decision-making architecture.

Conclusion

TeacherJi v2 is designed as an Autonomous Learning System, not a traditional chatbot or RAG application. The architecture deliberately separates decision-making from execution:

The Supervisor decides what should happen next.
The Learning Agent decides how to achieve the educational objective using tools.
The Memory Agent personalizes every decision with long-term learner knowledge.
The Reflection Agent verifies and improves outputs before they reach the student.

This separation of concerns keeps the architecture simple enough to maintain, while still demonstrating the core properties expected of modern agentic AI systems: planning, tool use, memory, reflection, and adaptive decision-making. It is a design that is both technically defensible and practical to implement and deploy on a free stack.
